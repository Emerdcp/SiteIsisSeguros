# Para que sua página seja encontrada no Google

Para que sua página seja encontrada no Google ou em outros buscadores quando alguém pesquisar palavras como **"seguros"** ou **"seguradora"**, você precisa **otimizar seu site para mecanismos de busca** — o que chamamos de **SEO (Search Engine Optimization)**.

## Site para analisar o site está ok

https://www.seobility.net/en/seocheck/

Analisa para sabe se falta algumas informações..



Aqui estão os **passos principais** para isso:

---

### ✅ 1. **Use palavras-chave no conteúdo da página**

Inclua as palavras *seguros*, *seguradora* e outras relacionadas de forma natural no:

* Título principal da página (tag `<h1>`)
* Parágrafos e descrições
* Títulos secundários (`<h2>`, `<h3>`)
* Textos alternativos das imagens (`alt="seguradora confiável"`)
* Links internos

---

### ✅ 2. **Configure as meta tags no `<head>` do HTML**

```html
<head>
  <title>Seguradora Confiável - Planos de Seguros para Você</title>
  <meta name="description" content="Oferecemos seguros de vida, auto e residencial com proteção completa. Conheça nossa seguradora e faça sua cotação!">
  <meta name="keywords" content="seguros, seguradora, seguro de vida, seguro auto, cotação de seguros, proteção, planos de seguros">
  <meta name="robots" content="index, follow">
</head>
```

> 📌 **Importante:** O Google atualmente não usa a tag `keywords` como fator de ranqueamento, mas ela ainda pode ser usada por outros buscadores. Foque mais na `title`, `description` e no **conteúdo real da página**.

---

### ✅ 3. **URL amigável**

Exemplo de URL boa:

```
https://www.minhaseguradora.com.br/seguros-auto
```

Evite URLs como:

```
https://www.minhaseguradora.com.br/page?id=432
```

---

### ✅ 4. **Adicione um sitemap e envie para o Google**

* Crie um arquivo `sitemap.xml`
* Cadastre seu site no [Google Search Console](https://search.google.com/search-console/)
* Envie o sitemap por lá

---

### ✅ 5. **Certifique-se de que o site é indexável**

No seu HTML **NÃO** deve haver:

```html
<meta name="robots" content="noindex">
```

---

### ✅ 6. **Outros pontos importantes**

* Site responsivo (funciona bem no celular)
* Boa velocidade de carregamento
* Conexão segura (HTTPS)
* Conteúdo original e útil
